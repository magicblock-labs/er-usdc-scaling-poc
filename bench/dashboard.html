All numbers are end-to-end: signed SPL-token transfers of delegated USDC (eATA → projected ATA) submitted over JSON-RPC sendTransaction. Validators here share one machine and contend for cores, so per-node TPS on dedicated hardware is at least the measured value; ephemeral validators share no state or consensus, so aggregate capacity scales with validator count for intra-shard traffic. Transfers across shards remain possible through Solana: state settles to the base layer, where funds move between rollups via commit + redelegation.
